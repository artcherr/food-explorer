# Food Explorer

Лёгкий каталог блюд и ресторанов на Next.js (App Router). Цель — быстрый UX: карусели блюд, детальные страницы и глобальный поиск.

## Стек
- Next.js 14 (App Router), TypeScript
- React (компоненты: `DishCard`, `Carousel`)
- CSS (глобальные стили `app/globals.css`)
- Данные: `data/dishes.json`, `data/restaurants.json`

## Запуск
```bash
npm i
npm run dev
# открой http://localhost:3000
